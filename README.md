# Đếm ngược ngày thi

Ứng dụng web (PWA) đếm ngược các môn thi, kèm danh sách việc cần làm cho từng môn và thông báo nhắc 6h / 13h / 19h.

Các file: `index.html` (giao diện + logic), `sw.js` + `tb.js` (offline và thông báo), `manifest.webmanifest` + các ảnh `icon-*`, `badge-96`, `notify-icon` (biểu tượng).
